# Glossary

`terms.csv` is the shared list of English science terms and the Hausa used for them in Kimiyya posts, so a term means the same thing every time.

- `hausa`: the term to use (blank = not decided yet).
- `note`: literal meaning, spelling variants, when not to use it.
- `reviewed`: `true` only once a native Hausa speaker has checked it.

Choosing a term, in order of preference:
1. A Hausa word people already use for it (ask non-scientists).
2. A descriptive phrase in everyday Hausa (*allurar rigakafi*, "injection of prevention").
3. An established loanword (*selu* for cell).

The first time a term appears in a script, give the English beside it. Add new terms here before using them in a script.
